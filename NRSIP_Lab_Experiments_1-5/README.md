# NRSIP Lab - Experiments 1 to 5

Source/configuration files prepared from the supplied **NRSIP Lab Manual (IT4501)**.

These experiments are Cisco Packet Tracer/GNS3 labs, so the `*.cfg` files contain Cisco IOS commands rather than a conventional programming-language source code.

## Experiments

1. VLAN Configuration and Inter-VLAN Routing
2. STP Verification and Root Bridge Election
3. IPv4 Subnetting and VLSM Design
4. IPv6 Configuration and SLAAC
5. Static and Default Route Configuration

## Important

The `output.txt` files contain the **expected lab outcomes from the manual**, not fabricated screenshots or live Packet Tracer console captures. For the college submission, run each topology in Packet Tracer/GNS3 and add your own screenshots of:
- the topology
- relevant `show` commands
- successful ping results

The configurations and addressing follow the supplied manual.
